# Release 0.0.1

## Summary

Initial local VSIX release of TechStack Multi Command Executor, supporting configured VS Code command workflows on Explorer selections, folders, workspaces, and glob matches.

## Features

- Named workflows with one or more ordered VS Code command steps and optional arguments.
- Include/exclude filters, preview and confirmation, and `afterEachStep`, `afterWorkflow`, or `never` save policies.
- Sequential per-file execution, progress, boundary-based cancellation, Output-channel diagnostics, and per-file run summaries.
- Multi-root workspace support.

## Migration

No migration is required. Configure workflows using `multiCommandRunner.workflows`; see [the user guide](../USER_GUIDE.md).

## Known issues and limitations

- Arbitrary VS Code commands may require a particular editor, selection, language extension, or user interaction.
- A running command cannot be interrupted by cancellation; its completion is awaited before the next cancellation check.
- Command side effects are not rolled back. Failed or interrupted `afterWorkflow` edits remain unsaved for review.
- The project README was left untouched per user direction and is included unchanged in the VSIX.
- `vsce` reports that repository and license metadata are missing. This package is for local installation; Marketplace publication was not attempted.
