# Release 1.2.0 — TechStack Multi Command Executor

## Summary
Release 1.2.0 introduces the complete Document-Driven Development structure, bundles the extension with `esbuild`, integrates ESLint for TypeScript code quality, adds full `.vscode` developer configuration, and cleans up release packaging.

## Features
- Run configured single-command or ordered multi-command workflows on selected Explorer resources, folders, workspaces, or glob patterns.
- Submenu contribution under Explorer context (`Run File Workflow`).
- Intersect workflow include/exclude glob filters with the execution scope.
- Interactive target preview QuickPick and safety confirmation before executing edits.
- Sequential execution engine with configurable save policies (`afterWorkflow`, `afterEachStep`, `never`).
- In-memory execution reporting with detailed error diagnostics and best-effort restoration of previously active editor.
- Bundled into a standalone, minified CommonJS bundle via `esbuild`.
- Dedicated `.vscode` configuration with debug launch configurations for multi-root workspaces.

## Migration
No breaking changes. The configuration setting `multiCommandRunner.workflows` and command identifiers remain identical and fully backward-compatible.

## Known Issues and Limitations
- Arbitrary VS Code commands may require a specific editor, language mode, or active selection.
- Commands executing long-running operations cannot be aborted mid-command; cancellation takes effect at the step/file boundary.
- Edits made during a workflow cannot be automatically rolled back if an external command mutates files on disk.
